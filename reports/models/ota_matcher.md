# Transfer test: the city-trained matcher on two real supplier feeds (MakeMyTrip x Goibibo)

Generated by `scripts/train/ota_matcher.py`. **Nothing was trained on these feeds.** The pair model, its vectorisers and its thresholds come from the 12-city open-data benchmark (`reports/models/city_matcher.md`); none of those cities' data came from these suppliers. There are no labels here, so this report gives counts and examples. A precision figure needs the label sheet at `data/processed/ota_matcher/label_sheet.csv`.

## Result

| Measure | Value |
|---|---:|
| MakeMyTrip properties / Goibibo properties | 15,168 / 4,000 |
| Candidate pairs after blocking | 25,723 |
| Accepted (p >= 0.956, both sides geocoded) | 546 |
| Uncertain (to the next cascade stage) | 2,664 |
| Name-only candidates held for review (a side has no usable coordinates) | 1,917 |
| Rejected | 20,596 |
| **Goibibo properties with an accepted MakeMyTrip twin** | **484 (12.1%)** |
| Goibibo properties with a twin under the naive rule (name JW >= 0.92 within 1 km) | 562 (14.1%) |
| Accepted pairs the naive rule misses | 63 |
| Naive-rule pairs the model does not accept | 179 |
| Accepted pairs after forcing one-to-one | 484 of 546 |

Accepted pairs: both feeds name the same city in 77.5% of them (city is not a model input, so this is an independent check); median distance 21 m, p90 246 m; 8.4% have name similarity below 0.85.
The gap between 546 accepted pairs and 484 one-to-one pairs is duplicates inside a feed: one hotel listed under two property IDs by the same supplier.

## Caveats

- 2016 crawls, samples of each catalogue: the overlap is a lower bound on what the full feeds share.
- 24% of MakeMyTrip properties have no usable coordinates. Their candidates come from name similarity alone and are held for review, never auto-accepted.
- MakeMyTrip marks 57% of properties as 1 star, which looks like its default for unrated; those ratings are treated as unknown.
- The accept threshold was calibrated for 99% precision on the open-data benchmark's weak labels. Whether it holds on these feeds is what the label sheet is for.
